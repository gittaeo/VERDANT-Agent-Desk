# 코인 가격·자산 구분 수정 · 2026-11-17

## 원인

기존 카드는 `priceUsd`를 USD로 보여주면서 통화·토큰 단위가 작게 표시됐습니다. 같은 심볼을 쓰는 다른 계약과 한 토큰의 여러 DEX 페어가 동일한 이름으로 나열됐습니다. 가격을 소수점 8자리로 제한해 1e-8보다 작은 양수가 0처럼 보일 수 있었고, 금액 포맷의 Number(null) 때문에 누락 금액이 0으로 표시될 수 있었습니다.

## 수정

- 가격은 `1 [심볼] 가격 · USD`, 유동성은 `선택 페어 유동성 · USD`로 구분. 원화가 아니라는 설명과 조회 시각 표시.
- 가격은 최대 6개 유효 숫자 보존. 아주 작은 값은 지수 표기로 유지하며 양수를 0으로 반올림하지 않음. 누락·비정상·0 가격은 미확인. 잔고·금액의 실제 0은 $0.00 유지.
- 가격 숫자를 읽기 쉬운 글꼴·크기로 표시. 좁은 화면은 가격과 유동성을 위아래 배치.
- 체인+토큰 계약별로 검색 결과를 묶어 최대 유동성 페어를 표시. 중복 페어는 먼저 제거. 같은 심볼의 다른 계약은 유지하고 경고·전체 계약 주소·거래쌍·DEX·원본 시세 링크 표시. 유동성이나 이름으로 공식 토큰 여부를 인증하지 않음.
- 이름 정확 일치 결과가 있으면 관련 이름 결과와 구분. 계약 주소 검색에서는 그 주소가 기초 토큰인 페어만 사용. 상대 토큰이 일치한다는 이유로 기초 토큰 가격을 잘못 표시하지 않음.
- 이전 분석 기록은 서버 JSON을 변경하지 않고 화면에서 동일 계약의 중복 카드만 감춤. 신규 조회에는 페어 수·가격 원문·단위·조회 시각을 저장.
- Codex 압축 자료에 체인·계약·심볼·페어가 유지되도록 수정. 모델 호출 없이 규칙 검사로 검증.
